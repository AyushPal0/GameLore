# AI Game Lore & Dialogue Engine

An AI-powered dynamic NPC dialogue system using:

- Transformers (GPT-2)
- Sentence Embeddings
- FAISS Vector Database
- Retrieval Augmented Generation (RAG)

## Features

- Dynamic NPC conversations
- Personality-based responses
- Lore consistency
- Memory tracking
- FastAPI backend
- Unity integration ready

## Tech Stack

Python
Transformers
FAISS
FastAPI
Streamlit

## How To Run

pip install -r requirements.txt

uvicorn server:app --reload
